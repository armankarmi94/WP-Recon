# 🔍 WP-Recon

ابزار خط فرمان (CLI) سبک و بدون نیاز به مرورگر به زبان پایتون برای شناسایی وب‌سایت‌های وردپرسی از نتایج موتورهای جستجو و استخراج دقیق قالب (Theme) و افزونه‌ها (Plugins) به همراه متادیتای رسمی از مخزن `wordpress.org`.

## ✨ ویژگی‌ها
- جستجوی عبارات فارسی و انگلیسی با قابلیت انتخاب صفحات دلخواه و تعیین سقف تعداد سایت‌ها
- بدون وابستگی به مرورگر یا درایورهای خارجی (کاملاً مبتنی بر درخواست‌های HTTP)
- تشخیص افزونه‌ها در سه سطح اطمینان (`api`, `high`, `medium`)
- استعلام خودکار نام رسمی، تاریخ آخرین بروزرسانی و وضعیت انتشار افزونه از API مخزن وردپرس
- تولید خروجی اختصاصی CSV برای هر دامنه و گزارش تجمیعی قالب‌ها
